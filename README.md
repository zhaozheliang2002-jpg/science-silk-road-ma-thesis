# Science Silk Road — MA Thesis Research Hub

A lightweight GitHub Pages workspace for an evolving MA thesis.

## What is editable?

- `data/research.json` — working questions, research-design options, dataset fields, open questions
- `data/papers.json` — literature database and personal notes on each paper
- `notes.md` — durable research log / scratchpad
- `index.html`, `styles.css`, `app.js` — site structure and appearance

## Recommended workflow

1. Edit `notes.md` freely for day-to-day research notes.
2. When a research question changes, update `data/research.json`.
3. Add each new paper to `data/papers.json` by copying one existing paper object and changing its fields.
4. Commit changes in GitHub. The static site updates from the repository files.

## Design principle

Keep the empirical research question simple. Treat theoretical concepts as analytical tools or findings unless the evidence justifies building them into the question.
